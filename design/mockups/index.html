CAAD — style mock-ups (phase 1.5a)

Pick one, or mix: the result becomes doc 10, the visual system.

Three directions, four scenes each

Each page shows the same four scenes (a part with its timeline and code, a feature dialog with preview, the sketch editor with dimensions, the right-click menu) in light and dark. The part is rendered from part.py by CAAD's own kernel (render.mjs), so the shading and edges are a real preview of the 3D look, not a drawing.

A — Studio

Calm and technical, a cleaned-up Onshape. Slim top bar with labelled tools, timeline and parameters in a left rail, dialogs and code docked on the right.

B — Islands

The view is the whole window; toolbar, timeline, dialogs and code float on frosted-glass islands. Icon-only toolbar with named tooltips; one tabbed island for timeline, parameters and parts.

C — Workshop

Warm and playful: paper and coral, chunky keyed buttons. A command dock on the left, the timeline as a strip along the bottom, a pie menu on right-click.

Chosen: A, with a Files | Timeline switch in the left rail; written down in docs/10-visual-system.md. Continued in A — Projects and files: browsing several projects, creating, renaming and removing projects and files, choosing the folder.

The same in all three, from doc 09: one place for dialogs (beside the view, never over the part); the timeline shows the names the code uses (sk1, sk2) and hovering a feature highlights its result in the view and its lines in the code; keys are shown in tooltips, menus and buttons; destructive actions happen at once with Undo in a message; the selection shows as a small chip only while something is selected; sketch mode swaps the commands but keeps the layout. Parts can be mixed, e.g. A's calm colours with B's floating layout, or C's bottom timeline in B.
